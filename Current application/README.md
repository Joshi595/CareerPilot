# Current application

Everything you upload when applying, in one place.

- **Your documents** (degree certificates, transcripts, reference letters, language certificates, work or residence
  permit…): add them once, in setup or under Profile › Application details, or copy them here yourself. They stay.
- **The CV and cover letter** of the application you have open in JobGambit appear here and change when you open
  another application. When you mark it applied they leave this folder; JobGambit keeps them in its archive.

Only this README is part of the repository: nothing else in this folder is ever committed.
